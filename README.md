🍔 Food Ordering Website

A simple and responsive Food Ordering Website built using HTML, CSS, and JavaScript. The project provides a basic user interface to browse food items, add them to a cart, and simulate an online ordering experience.

🚀 Features
🍕 Browse food items
🛒 Add and remove items from cart
💰 View total price in cart
📱 Responsive design for all devices
⚡ Interactive UI using JavaScript

🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript 
Tools: VS Code, Git, GitHub
📂 Project Structure
Food-Ordering-Website/
├── index.html
├── style.css
├── script.js
├── images/
└── README.md

⚙️ How to Run the Project
Clone the repository:
git clone https://github.com/sneha-raj16/Food-Ordering-Website.git
Open the project folder:
cd Food-Ordering-Website
Run the project:
Simply open index.html in your browser
